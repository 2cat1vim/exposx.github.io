Manual

Options

exposx -h    usage / help
exposx -v    verbose
exposx -s    stdin

Commands

Once started, exposx opens a prompt:

exposx$ search <id | name>
exposx$ poc <id>
exposx$ export <id> <json | pretty>
exposx$ update
exposx$ exit
search <id | name>
Asks the server for a CVE and returns it.
poc <id>
Proof of concept for a CVE.
export <id> <json | pretty>
Exports a CVE as raw JSON or readable text.
update
Checks the latest release on GitHub and updates exposx if you accept.
exit
Quits exposx.

Work in progress: poc and export are not implemented yet, and search is still being wired to the server.

How it works

Every day at 07:30 (Paris time) the server calls the NVD API, stores the new CVEs in SQLite and removes those older than 365 days. The client talks to the server to get its results.
