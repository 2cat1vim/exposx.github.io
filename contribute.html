Contribute

Exposx is written in C, for fun and the love of the game.

Source

github.com/2cat1vim/exposx

client/   the CLI scanner (cli.c)
server/   the CVE server (srv.c)

Build

cd client && make     # exposx client
cd server && make     # exposx-server
./exposx-server 8080

The code is compiled with -Wall -Wextra -Werror: it must build without any warning. The client connects to the server on 127.0.0.1:8080.
