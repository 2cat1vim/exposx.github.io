Self-host

Use the official server, or run your own. For companies and individuals alike.

How it works

NVD API ──daily──▶ exposx server  ◀──query─── exposx client
                   (CVE database) ───reply──▶
NVD API
   │  daily update
   ▼
exposx server   (CVE database)
   ▲  query
   │  reply
   ▼
exposx client
  • The server feeds itself: every day at 07:30 (Paris time) it pulls the new CVEs from the NVD API, stores them, and removes those older than 365 days.
  • The client only talks to the server: it sends a query and gets the reply back. It never calls the NVD itself.

Two ways to use exposx

1. Client only — official server
Install the client and you are done. It queries the official exposx server, which is kept up to date for you. Nothing to host, nothing to maintain.
2. Client + your own server
Run the server on your own machine or network. Your searches never leave your infrastructure: useful for companies with security or compliance rules, or for anyone who wants full control.

Run your own server

Needs make and a C compiler.

git clone https://github.com/2cat1vim/exposx.git
cd exposx/server
make
./exposx-server 8080

The server is built to update its CVE data by itself every day: no cron job, no manual import.

Connect the client to it

In another terminal, build and start the client from the same clone:

cd exposx/client
make
./exposx_linux

Every search is now answered by your server.

Work in progress: the server currently listens on 127.0.0.1 and the client connects to 127.0.0.1:8080, so both run on the same machine. Reaching a server over the network, choosing the server address in the client, and the daily NVD sync are on the roadmap.

Docker

The server is not in the Docker setup yet. You are free to put it in your own container.
