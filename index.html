CVE Scanner

Common Vulnerability Exposure — Command Line Interface. Written in C, no AI.

★ Star on GitHub Install

Exposx keeps only the latest CVEs (last 365 days). A small C server pulls new vulnerabilities from the NVD every day, and the C client lets you query them from your terminal.

Two ways to use it

  • Client only — install the client, it queries the official exposx server.
  • Self-hosted — run your own server for your company or at home. It feeds itself from the NVD every day and your queries stay on your network. How →

Features

  • On start, shows the 3 latest most critical CVEs.
  • Search a CVE by id or name.
  • Export a CVE as JSON or pretty text.
  • Built-in self-update from GitHub releases.
  • Runs on Linux and macOS.

Roadmap

C client scanner → C server on a VPS → Docker image on the GitHub package registry.

Exposx is in early development: some commands are not implemented yet.
