CVE Scanner

Common Vulnerability Exposure — Command Line Interface. Written in C, no AI.

★ Star on GitHub Install

Exposx keeps only the latest CVEs (last 365 days). A small C server pulls new vulnerabilities from the NVD every day, and the C client lets you query them from your terminal.

Two ways to use it

Client only

Install the client and you are done: it queries the official exposx server, kept up to date for you.

Install →

Self-hosted

Run your own server for your company or at home. It feeds itself from the NVD every day and your queries stay on your network.

Self-host →

Features

Critical first

On start, shows the 3 latest most critical CVEs.

Search

Find a CVE by id or by name.

Export

Get a CVE as raw JSON or pretty text.

Self-update

Updates itself from the GitHub releases.

Linux & macOS

Native C client, Docker for everything else.

Last 365 days

Only recent CVEs: small, fast, relevant.
