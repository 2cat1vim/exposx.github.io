Install

Exposx runs on Linux and macOS.

Requirements

  • make and a C compiler (cc / clang)
  • libcurl (libcurl4-openssl-dev)
  • libarchive (libarchive-dev)

On Debian/Ubuntu, make checks these packages and installs the missing ones with apt-get (it asks for sudo).

Build the client

git clone https://github.com/2cat1vim/exposx.git
cd exposx/client
make

This produces the exposx_linux binary (or exposx_darwin on macOS).

Run

./exposx_linux

Run it from the client folder: it reads its version from the .exposx file next to it. Do not edit that file.

Update

Inside exposx, type update. It compares your version with the latest GitHub release and asks before downloading.

Windows and others

A docker-compose.yml is planned to run the client on Windows or any other system. Only the client goes in Docker: the server calls the internet every day to update its CVE data, so hosting your own would not help.
