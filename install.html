Install

Download the latest release, build it, run it.

Linux

Debian / Ubuntu. make installs libcurl, libarchive and clang if they are missing (it asks for sudo).

TAG=$(basename "$(curl -fsSLI -o /dev/null -w '%{url_effective}' https://github.com/2cat1vim/exposx/releases/latest)")
curl -fsSL "https://github.com/2cat1vim/exposx/archive/refs/tags/$TAG.tar.gz" | tar xz
cd "exposx-$TAG"
make
./exposx_linux

macOS

Needs the Xcode command line tools (xcode-select --install) and Homebrew.

brew install libarchive
TAG=$(basename "$(curl -fsSLI -o /dev/null -w '%{url_effective}' https://github.com/2cat1vim/exposx/releases/latest)")
curl -fsSL "https://github.com/2cat1vim/exposx/archive/refs/tags/$TAG.tar.gz" | tar xz
cd "exposx-$TAG"
cc -o exposx cli.c -lcurl -I"$(brew --prefix libarchive)/include" -L"$(brew --prefix libarchive)/lib" -larchive
./exposx

Windows (Docker)

Install Docker Desktop, then run this in PowerShell. It downloads the latest release inside a Linux container, builds it and starts exposx.

docker run -it --rm debian:bookworm bash -c 'apt-get update && apt-get install -y curl ca-certificates make gcc clang libcurl4-openssl-dev libarchive-dev && TAG=$(basename $(curl -fsSLI -o /dev/null -w %{url_effective} https://github.com/2cat1vim/exposx/releases/latest)) && curl -fsSL https://github.com/2cat1vim/exposx/archive/refs/tags/$TAG.tar.gz | tar xz && cd exposx-$TAG && make && ./exposx_linux'

The container is removed when you exit, so the next run downloads and builds again (about a minute). This also works on any system with Docker.

This installs the client, which uses the official exposx server. To run your own server, see Self-host.

Run

Run exposx from the folder you extracted: it reads its version from the .exposx file next to it. Do not edit that file.

Update

Inside exposx, type update. It compares your version with the latest GitHub release and asks before downloading.

All releases: github.com/2cat1vim/exposx/releases
